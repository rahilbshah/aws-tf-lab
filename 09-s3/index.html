🪣 Served straight from S3

No EC2. No load balancer. No servers at all — this page is an object in a bucket, and S3 is serving it over HTTP.

How it works: the bucket has a website_configuration naming index.html as the index document, Block Public Access is disabled, and a bucket policy allows s3:GetObject to everyone.

Note: the S3 website endpoint is HTTP-only. HTTPS (and caching) needs CloudFront in front.

Try a URL that doesn't exist to see error.html.
