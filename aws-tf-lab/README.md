SAA-C03 study vault. Reference notes at the root; night-before reads in `revision/`; templates in `_templates/`. The tables below are **live Dataview queries** — they update themselves whenever a note's frontmatter or `#weak-spot` tags change, so this page is never hand-maintained.

> [!info] How this vault works
> - **Reference notes** (`NN-topic.md`) — teaching + worked examples. Frontmatter drives the tables below (`topic`, `domain`, `status`).
> - **Revision docs** (`revision/NN-topic-revision.md`) — the night-before read, generated verbatim from the note, each ending in a **self-test** that blanks out the note's comparison tables and traps. Recall is not the problem; telling two neighbouring answers apart is, so that is what the self-test drills.
> - **Self-test, not flashcards.** The `cards/` folder was deleted on 2026-09-06: 368 cards written, 3 ever reviewed, and being hand-written they drifted out of step with the notes. Nothing is hand-maintained now.
> - **Weak spots** — tag `#weak-spot` on any note surfaces it in the query below and in the Tag pane.
> - `status`: `draft` → `reviewed` → `mastered`. The mock-exam generator only pulls `reviewed`/`mastered` notes.

## All topics
```dataview
TABLE domain, status, file.mtime as "Updated"
FROM ""
WHERE topic AND !contains(file.path, "revision/") AND !contains(file.path, "_templates/")
SORT file.name ASC
```

## Weak spots — all topics
```dataview
LIST
FROM #weak-spot
```

## Status breakdown
```dataview
TABLE length(rows) as "Count"
FROM ""
WHERE topic AND !contains(file.path, "revision/") AND !contains(file.path, "_templates/")
GROUP BY status
```
